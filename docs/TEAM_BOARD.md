# Petra team board

This is a lightweight orientation page for humans + ephemeral coding agents. **Live GitHub Issues/PRs are authoritative.**

## Current program
1. Scientific flagship: reproducible spatial *E. coli* + ciprofloxacin evolution.
2. Engine: deterministic hybrid spatial stochastic simulator.
3. Experience: living Petri dish with intervention tools, progressive zoom, lineage/event storytelling, branching experiments, and provenance.
4. Validation: model-level reference cases before adding breadth.
5. Extensions: persistence, phage, competition/HGT, collateral sensitivity, temperature, ML acceleration/explanation.

## How to work
- Read root `AGENTS.md` and the nearest child contract.
- Choose/claim an Issue before substantial edits.
- Put scope, branch, paths, capability limits, and acceptance intent in the claim.
- Keep one active implementation branch where practical.
- Coordinate before editing hot shared contracts.
- Leave an exact GitHub checkpoint before an ephemeral session ends.

## High-conflict ownership surfaces
- `docs/science/SCIENTIFIC_MODEL.md`
- `data/presets/ecoli_ciprofloxacin_v1.json`
- simulator state/schema and worker protocol once created
- central design tokens / dish renderer
- `research/CLAIM_LEDGER.md`

## Capability routing
Use Issue text/title to state when work needs browser/GPU profiling, visual review, biology review, or human competition-demo acceptance. Source-only agents should pick work they can actually advance.

## Definition of a useful handoff
Issue/PR + branch + commit SHA, changed paths, observed verification, science/provenance changes, remaining gates, conflict risk, next action.
