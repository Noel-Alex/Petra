# Petra Idea Incubator DOX

## Purpose

Preserve promising science/product/interaction ideas without turning every thought into active implementation work.

## Local contracts

- One Markdown file per idea.
- Append-only by addition after merge: do not rewrite history to make an old idea look correct.
- Each card separates **Evidence**, **Inference**, **Proposal**, **Risks**, and **Promotion gate**.
- An idea card is not a work claim. GitHub Issues are the executable queue.
- Scientific ideas require credible sources; interaction ideas should identify user value and measurable acceptance.
- Do not create filler cards to satisfy a quota.

## Promotion

Promote an idea to a GitHub Issue only when it has a coherent scope, dependencies, acceptance criteria, and a realistic owner/slice.
