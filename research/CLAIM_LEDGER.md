# Scientific claim ledger

This is the compact contract between Petra's interface, simulator, and evidence base.

| Petra behavior/statement | Class | Basis | Limit / transfer note |
|---|---|---|---|
| Growth slows when a limiting resource is depleted | mechanistic approximation, strongly grounded | Monod/consumer-resource literature; spatial colony work | one/few resources, not full metabolism |
| Petra's current flagship has a source-matched measured `mu_max` / `K_s` / yield package | **false** | flagship resource context is not yet identified; Nev 2021 / LaCroix 2015 / Shao 2017 differ in temperature, medium, units, or parameter coverage | keep growth parameters UNBOUND until the limiting-resource/medium/unit context is versioned |
| Petra's research-stage flagship may use the versioned `ecoli-ciprofloxacin-ecology-engineering` profile to execute resource-limited ecology in model units | engineering | explicit scenario-owned normalized execution profile; behavior targets are kernel invariants, not literature fits | not a measured MG1655/glucose/CFU/dry-weight parameter set; physical Science-Mode growth values remain UNBOUND |
| Petra's baseline composed parameter set may bind the source-backed ciprofloxacin PD/MIC authority while carrying an all-zero initial concentration landscape | engineering composition identity + transferred mechanism binding | versioned `ecoli-ciprofloxacin-baseline-composed@1.1.0` record bound to the declared resource×drug loss policy, Regoes reference curve, and Marcusson genotype MIC table | zero initial exposure means **inactive incremental ciprofloxacin loss**, not a measured MG1655 background death rate; protocol-v5 mutable exposure remains checkpoint/command state; initial resource/inoculum remain run-state inputs |
| Independently mixing a 37 °C MG1655 growth rate, a 30 °C MG1655 half-saturation fit, and a third-study yield creates one measured parameter set | **false** | assay-compatibility boundary | such a composition is a calibration/transfer and must be labelled/versioned as one |

| The current flagship ciprofloxacin landscape is a physically calibrated dish diffusion/decay model | **false** | protocol-v5 concentration-field authority + #633 release decision | `mg/L` is authoritative field state for PD/replay, but Petra does not assign a physical mm/time transport law, decay/clearance law, or calibrated delivery geometry in the current flagship; future physical transport requires a new versioned scenario calibration |

| Plasmid transfer is a universal fixed probability per cell | **false** | conjugation literature | encounter, engagement, host/plasmid, density matter |

| Each rendered bacterium is literally one simulated bacterium | **false** | rendering architecture | visuals sample/aggregate local state |
| Petra predicts human antibiotic treatment outcomes | **false** | scope | not a clinical tool |
