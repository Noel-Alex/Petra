# Competition and consumer-resource ecology

## Design choice
Petra should prefer explicit resource/space competition over arbitrary pairwise “attack coefficients” for the core experience.

When two populations consume the same local resource, competition emerges from:
- resource depletion;
- uptake/growth differences;
- spatial access;
- local capacity;
- environmental tolerance.

This is both interpretable to students and compatible with mechanistic extensions.

## Lotka-Volterra
Generalized Lotka-Volterra (gLV) models are useful phenomenological summaries and can fit competition data (for example DOI `10.3389/FMICB.2020.572487`), but fitted pairwise interactions need not remain valid after resources/environment change. Consumer-resource models expose the hidden resource state that gLV compresses.

## Petra rule
- core cross-lineage competition: shared resources + space;
- direct inhibition/cooperation only as explicit sourced mechanisms;
- future metabolites/cross-feeding get their own fields/reactions;
- do not describe a visually introduced “fungus” as biologically realistic until its own parameter set exists.
