# Phage life history and host physiological state

Phage parameters are not constants independent of the bacterial host's condition.

## Evidence
- Hadas et al. 1997, DOI `10.1099/00221287-143-1-179`: T4 adsorption/development changed with *E. coli* growth rate; burst size increased and eclipse/latent periods decreased as host growth rate increased.
- You, Suthers & Yin 2002, DOI `10.1128/JB.184.7.1888-1894.2002`: T7 growth in *E. coli* depended on host physiological state; eclipse time decreased and production rate increased with host growth.
- Classic lytic population models use adsorption, latent period/delay, burst size, free-phage loss, and host growth.

## Petra rule
The first Science Mode phage scenario should use a named host/phage pair. Host resource/growth state should modulate phage development when supported rather than using a fixed “burst = 100” for all conditions.

A generic phage sandbox can exist, but its parameters must be labeled experimental/user-defined.
